# The Institute — build handoff

Everything Claude Code needs to build the site.

```
CLAUDE.md              start here — build instructions and the non-negotiable rules
DESIGN.md              grounds, hover, depth, motion. Fixes what was flat in v1.
STRUCTURE.md           sitemap, routes, page inventory, template list
BRAND-TOKENS.css       the palette, every ratio measured. Copy into app/globals.css
content/site.ts        every string that is not page body copy
content/navigation.ts  the complete menu system
assets/                seal, mark, hero field, engraved tiles
```

## In one paragraph

Dark shell, always — no light mode. An ivory Page sits inside it for anything read at length.
Fraunces for titles, Source Sans 3 for everything read. Gold is rare and never touches the Page.
Five doors: Begin Here, Concepts, Courses, Books, Live Events, with Membership on the utility
rail. The Foundation Course gates *study* but never browsing or buying. Search `content/` for
`needsMichael` to find what has not been written yet — ship the route and a placeholder, never
invented copy.
